# 🛒 DEAL SCANER

Автоматизированный скрипт с графическим интерфейсом (GUI) на Python для постоянного мониторинга сделок на предметы в Steam (CS2, Dota 2, Rust и др.). Бот проверяет стоимость скина в реальном времени, ведет локальную базу данных цен и мгновенно отправляет красивое HTML-уведомление на вашу почту, когда цена падает ниже установленного вами лимита.

## ✨ Основные возможности

- **Интерфейс в стиле Steam:** Глубокая темная тема, полностью повторяющая оригинальный дизайн торговой площадки.
- **Умный поиск:** В поле предмета можно вводить как технический ID лота (например, `G18DF363004`), так и прямое имя предмета (например, `AK-47 | Redline (Field-Tested)`). Бот сам разберется и подтянет официальное `market_hash_name`.
- **Многопоточность:** Проверка цен и запросы к API выполняются в фоновом режиме, поэтому интерфейс программы никогда не зависает.
- **Локальная БД (SQLite):** История всех успешных проверок сохраняется в базу данных `steam_monitor_base.db` для последующего анализа графиков цен.
- **Защита от банов (Rate Limit):** Бот имеет встроенный случайный тайм-аут между запросами (30+ секунд), чтобы Steam не заблокировал ваш IP-адрес за спам-запросы.
- **Графические Email-нотификации:** При срабатывании триггера на почту приходит сверстанное HTML-письмо с прямой кнопкой перехода на торговую площадку.

## 🚀 Инструкция по подготовке и запуску

### 1. Требования к системе

Для работы бота необходим установленный **Python версии 3.8 или выше**.
Компоненты интерфейса (`tkinter`) и работы с почтой/БД уже встроены в Python по умолчанию.

### 2. Установка зависимостей

Скрипту необходима только библиотека `requests` для отправки сетевых запросов к серверам Steam. Откройте терминал/командную строку в папке с проектом и выполните команду:

### 3. Настройка почты (Важно!)

EMAIL_SETTINGS = {
"smtp_server": "smtp.yandex.ru", # Менять не нужно, если отправляете с Яндекса
"smtp_port": 465, # Порт для SSL-соединения
"sender_email": "ВашаПочта@yandex.ru", # Почта-отправитель
"sender_password": "xxxx xxxx xxxx xxxx", # Специальный ПАРОЛЬ ПРИЛОЖЕНИЯ (не от аккаунта!)
"receiver_email": "КудаПридетПисьмо@mail.ru" # Ваша основная почта для уведомлений
}

```bash
pip install requests
```

> ⚠️ **Внимание:** Обычный пароль от ящика Яндекс/Mail.ru **не подойдет** из-за систем безопасности почтовых сервисов. Вам необходимо зайти в настройки безопасности своего Mail/Yandex аккаунта, найти пункт **"Пароли приложений"**, сгенерировать новый пароль для "Почты" и вставить этот 16-значный код в поле `sender_password`.

### 4. Запуск бота

Запустите скрипт через терминал:

```bash
python main.py
```

_(Замените `main.py` на реальное имя вашего `.py` файла, если оно отличается)_

## 🛠 Инструкция по использованию

1. **App ID игры:** По умолчанию стоит `730` (для CS2/CS:GO). Если вам нужна другая игра, укажите её ID из Steam (например, `570` для Dota 2, `252490` для Rust).
2. **Название предмета или ID:** Вставьте технический ID предмета из вашей системы или введите оригинальное англоязычное имя скина из Steam.
3. **Целевая цена выкупа:** Укажите максимальную стоимость в рублей, при достижении которой вы хотите получить уведомление (например, `1000.0`).
4. Нажмите кнопку **"Запустить мониторинг"**. Бот проверит имя, сделает первый запрос и начнет циклический обход.
5. Чтобы остановить бота вручную в любой момент, нажмите кнопку **"Остановить мониторинг"**.

## 📝 Логирование ошибок

Все статусы запросов отображаются в интерактивной консоли внутри приложения:
!_ `Код 429` — Steam временно ограничил запросы с вашего IP. Бот автоматически перейдет в режим ожидания и попробует снова через минуту.
!_ `success: false` — Проверьте правильность ввода ID предмета или App ID игры.
